# LanChallenge - Personalized Vocabulary Trainer

**LanChallenge** là ứng dụng Android giúp người dùng học và luyện tập từ vựng cá nhân hóa thông qua các bài test trắc nghiệm, hỗ trợ quản lý dữ liệu linh hoạt từ file `.txt`.

---

## Tính năng chính
* **Quản lý từ vựng:** Thêm, sửa, xóa từ vựng cá nhân hóa.
* **Nhập/Xuất dữ liệu (.txt):** Tích hợp SAF để đọc/ghi file từ bộ nhớ máy.
* **Thuật toán ôn tập:** Luyện tập trắc nghiệm thông minh dựa trên lịch sử từ hay sai.
* **Đăng nhập & Đồng bộ:** Xác thực tài khoản với Firebase.

---

## Kiến trúc & Công nghệ 
* **Language:** Kotlin.
* **UI:** XML Layouts, Material Design.
* **Architecture:** Model-View-ViewModel / Clean Architecture.
* **Database & Storage:** Room Database, File I/O, ContentResolver.
* **Backend:** Firebase Auth.
